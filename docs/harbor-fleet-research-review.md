### Reproducibility and validation

The exact read-only AIS queries were:

```sql
SELECT mmsi,name,call_sign,first_seen,last_seen,fixes,max_sog_knots,terminals_json
FROM sightings ORDER BY mmsi;
SELECT mmsi,terminal_id,slip_id,confidence,ambiguous,since,until
FROM dwells WHERE mmsi = '368120620';
```

They were executed with `new DatabaseSync(databasePath, {readOnly: true})`; no database writes or schema changes were made. The proposal was parsed as JSON and counted without rewriting it. Vessel coverage was checked against all 128 document rows. PSIX matching used exact official number plus US flag and rejected rows labeled DUPLICATE. Certificate history inspection selected Issued/Effective entries, including amendments, rather than accepting the first dated record or a stale Valid label. One initial automated detail-link extraction failed to decode HTML entities; that extraction was corrected and all 91 detailed records were retrieved successfully before this report was completed.

This is a documentary review. No application unit/E2E tests, manual passenger-service observation, title-abstract retrieval, or onboard COI inspection was performed. The checked local artifacts are the proposed JSON, the original research, the FCC snapshot and the read-only AIS database. The final review file is validated with `git diff --check`, exact row/finding counts and Markdown reference-target checks before commit.
